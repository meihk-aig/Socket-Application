# Socket-Application
Đồ án xây dụng một ứng dụng nhắn tin trong mạng WLAN

# Hai file demo
- Khiêm vừa thêm hai file demo socket bằng TCP
- Lưu ý cần chạy file server trước rồi mới chạy client kết nối vào
- Hãy thay biến SERVER bằng IPv4 của máy bạn để kết nối thành công (vào terminal gõ "ipconfig" để biết IPv4 của máy)
- Hiện tại phiên bản này chỉ có thể gửi client -> server và phải đóng thủ công bằng cách kill terminal
